# AOTUS

All Of The Unified — S.

A desktop LLM workspace. Unified interface to multiple LLM providers with persistent memory, streaming chat, and an agent tool workspace.

## Stack

- **Frontend**: Svelte 5, TypeScript
- **Backend**: Rust (Tauri v2)
- **Databases**: SQLite + vector search (sqlite-vec)

## Getting started

```bash
npm install
npm run tauri dev
```
